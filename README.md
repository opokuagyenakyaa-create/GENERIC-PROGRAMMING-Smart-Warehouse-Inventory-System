# Generic Programming — Smart Warehouse Inventory System

## About
This project was created as a case study activity for EL 162 — Object Oriented Programming at the University of Mines and Technology (UMaT), Tarkwa. It demonstrates generic programming in Python through a smart warehouse inventory system.

## Task Summary
A logistics company stores different categories of items including electronic devices, books, food products and spare parts. Rather than developing separate storage classes for each category, the company wants a reusable storage system using generic programming.

## What the Code Does

### Trial Activity
- Creates a generic class Storage[T] that can store one item of any data type
- Implements store() and retrieve() methods
- Demonstrates using an integer, string and list

### Case Study Activity 2
- Creates a generic class Inventory[T] that stores multiple items of any type
- Implements store(), retrieve() and display() methods
- Demonstrates using str for product names, int for stock quantities, float for prices and list for serial numbers

## Concept Demonstrated
Generic Programming — one class that works with any data type
